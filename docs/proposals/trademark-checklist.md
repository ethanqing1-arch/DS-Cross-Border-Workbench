# 跨浪商标检索清单

供人工在中国商标网检索和记录。检索日期、命中记录及人工复核意见待填。

## 待查名称

| 名称 | 检索时输入的形式 |
|---|---|
| `跨浪` | 原词及同音、近音、近形文字。用商标名称查，按下列类别做近似查询 |
| `Kualang` | 原拼写、`Kua Lang` 和近似拼写。分别查看英文字母形式和与中文组合的记录 |
| `getkualang.com` | 域名完整文字、`getkualang` 和其中的 `Kualang`。如查询字段不接受句点，记录该限制与实际使用的检索词 |

## 待查类别

先按以下三类检索，再根据产品实际交付形态，用《类似商品和服务区分表》细化商品或服务项目和类似群。商标局的分类页面提供第十三版（2026 文本）下载。类别及项目的最终范围由用户和商标专业人员确认。[中国商标网商品和服务分类](https://sbj.cnipa.gov.cn/spfwfl/index.html)

| 类别 | 为什么纳入检索 | 待核对的商品或服务 |
|---|---|---|
| 第 9 类 · 计算机软件 | 跨浪工作台有本地部署和安装包，名称会用在可下载软件上 | 可下载的计算机程序、已录制或可下载的计算机软件平台 |
| 第 35 类 · 广告与销售相关服务 | 工作台面向跨境电商，支持广告和销售工作流。若同名品牌还用于向他人提供相关商业服务，需要核对其服务项目 | 广告、为他人推销、商业管理辅助，按实际对外提供的项目复核 |
| 第 42 类 · 技术服务 | 如果以该名称提供在线工作台、托管或软件开发服务，需要检查相关技术服务项目 | 软件即服务（SaaS）、计算机软件设计和开发，按实际服务复核 |

第 35 类尤其需要核对服务对象和内容。把品牌用于向他人提供广告或推销服务的情况逐项登记，由人工对照实际业务判断。[商标局第 35 类服务指引](https://www.cnipa.gov.cn/attach/0/762552d25fb743458cbc048a71a8c083.pdf)

## 中国商标网检索路径

1. 在中国商标网首页打开「商标查询 → 网上查询」，阅读使用说明，勾选「我接受」后点「进入查询」，按提示注册或登录。也可从国家知识产权公共服务平台的「信息服务 → 商标 → 商标查询」进入。[中国商标网查询入口](https://sbj.cnipa.gov.cn/trademark-query) · [国家知识产权公共服务平台](https://ggfw.cnipa.gov.cn/homeindex) · [国家知识产权局数据使用手册](https://ggfw.cnipa.gov.cn/portal/helper/%E7%9F%A5%E8%AF%86%E4%BA%A7%E6%9D%83%E6%95%B0%E6%8D%AE%E4%BD%BF%E7%94%A8%E6%89%8B%E5%86%8C%E5%8F%8A%E5%BC%80%E6%94%BE%E7%9B%AE%E5%BD%95.pdf)
2. 用「商标综合查询」逐项查三个名称的原词、拆分词及变体，再以七个实体全称做申请人查询。按实际输入条件记录命中与未命中。
3. 用「商标近似查询」按第 9、35、42 类分别查中文、拼音和英文，参考「商品/服务项目查询」核对具体项目。图标定稿后，按其构成要素由人工选图形编码，再补查图形和图文组合。[商标局商品分类查询指引](https://www.cnipa.gov.cn/jact/front/mailpubdetail.do?sysid=13&transactId=332534) · [商标局图形查询指引](https://www.cnipa.gov.cn/jact/front/mailpubdetail.do?sysid=13&transactId=339444)
4. 对每个待复核命中，打开详情记录申请号或注册号、申请人、申请日期、类别、类似群和指定项目。再用「商标状态查询」及「商标公告查询」交叉记录状态与公告日期，保存页面或截图。官方查询数据有更新滞后，记录查询时点并在决策前复查。[商标局查询状态答复](https://www.cnipa.gov.cn/jact/front/mailpubdetail.do?sysid=13&transactId=395234) · [商标局数据更新答复](https://www.cnipa.gov.cn/jact/front/mailpubdetail.do?sysid=13&transactId=461250)

## 人工复核

- 用户确认对外使用的中文、英文、域名与图标版本，以及软件交付形态、服务对象和拟覆盖的商品或服务。
- 商标专业人员对照命中记录和实际业务，复核名称的读音、字形、含义、整体图形，以及指定项目、类似群和交叉检索范围。
- 对七条主体线索核对申请人名称与官方记录的对应关系。涉及曾用名、转让、状态变化或需进一步核实的在先权利时，另记核对证据。
