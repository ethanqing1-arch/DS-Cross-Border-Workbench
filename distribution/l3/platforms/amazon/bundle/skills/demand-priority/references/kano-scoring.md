# Kano 判定与付费意愿估算细则

供 `demand-priority` 步骤 4、6 执行。所有分类必须落到可复算的数字，不接受「感觉像兴奋型」。

## 1. Kano 四类判定矩阵

先算三个基础量：

| 量 | 算法 | 说明 |
|---|---|---|
| 提及率 `mention_rate` | 提及该痛点的去重句数 ÷ 该品类总痛点句数 | 0–1 |
| 缺失即差评率 `missing_bad_rate` | 提及该痛点且评分 ≤2 的条数 ÷ 提及该痛点的总条数 | 0–1 |
| 满足率 `satisfied_rate` | 提及该痛点且评分 ≥4 的条数 ÷ 提及该痛点的总条数 | 0–1 |
| 星级相关 `r` | 该痛点提及（0/1）与评分的 Pearson 相关 | −1~+1，负相关表示提及越多分越低 |

判定（按序，命中即停）：

| 顺序 | 类型 | 条件 |
|---|---|---|
| 1 | 基本型 | `mention_rate` ≥0.40 且 `missing_bad_rate` ≥0.30 |
| 2 | 期望型 | `mention_rate` 0.15–0.39 且 `r` ≤−0.30 |
| 3 | 兴奋型 | `mention_rate` <0.15 且 `intensity_score` ≥4 且 `satisfied_rate` <0.20 |
| 4 | 无差异型 | `improvable_score` ≤3 或 `gap_score` <4.0，或上述全不命中 |

补充规则：
- 基本型同时满足兴奋型条件时，归基本型（安全优先）。
- `mention_rate` ≥0.40 但 `missing_bad_rate` <0.30 → 归期望型（大家都在提但没到「没有就差评」）。
- 无法计算 `r`（样本 <50）→ 期望型判定改用 `mention_rate` 0.15–0.39 单条件，标 C。

## 2. 付费意愿三路证据

### 2.1 价格带路

```
spread_ratio = (P75 - P25) / P50        # 竞品价格四分位
≥0.45 → 4 分
0.25–0.44 → 3 分
<0.25 → 2 分
```

理由：价格带越宽，说明市场对「更好」愿意付溢价；价格带极窄说明同质化、只拼低价。

### 2.2 文本路

| 文本信号 | 分值 |
|---|---|
| `would pay`, `worth the extra`, `gladly pay more`, `upgraded to`, `switched from X because` | 4 |
| `wish it had`, `if only`, `missing` | 3 |
| 无相关表述 | 2 |
| `overpriced`, `not worth`, `cheaper elsewhere`, `waste of money` | 1 |

统计口径：该痛点簇内出现上述短语的句子数 ≥10 才可作为依据；<10 条按「无相关表述」处理。

### 2.3 替代品路

在独立站/DTC 找同类改进款：

- 存在 ≥2 个改进款且售价 ≥ Amazon 中位价 ×1.30 → 5 分。
- 存在 1 个 → 4 分。
- 不存在 → 不加分（不高于文本路）。

### 2.4 合成

取三路最高档；三路冲突（最高与最低差 ≥2 档）时取最低档，并写 `wtp_basis=conflict:price4/text1/alt2`。

## 3. 机会缺口与优先级

```
gap_score = (0.40 × f + 0.35 × i + 0.25 × w) × 2
```

| gap_score | 含义 | 默认动作 |
|---|---|---|
| 8.5–10.0 | 强缺口，需求明确且愿意付费 | P0（需过可改进性 ≥6） |
| 7.5–8.4 | 有缺口，可验证 | P0（需 Kano 非兴奋型）或 P1 |
| 6.0–7.4 | 弱缺口 | P1（小样验证） |
| 4.0–5.9 | 边缘 | P2 |
| <4.0 | 无机会 | P2，不进产品定义 |

## 4. 成本校验（交 `profit-model`）

对每个 P0 项，把以下字段传给 `05-product/profit-model`：

| 字段 | 取值 |
|---|---|
| `cogs_cny` | 原采购价 + `cost_delta_usd × FX` |
| `price_usd` | 原价（不主动涨价；若计划涨价须单独出一版） |
| `ad_share` | 新品期 0.35（规范 4.1 区间中值） |

判定：触发任一条 → `redline_hit` 记录并降 P1。
- 毛利率 <30%
- 贡献利润率 <8%
- 贡献利润 <3 USD/件

## 5. 典型误判与纠正

| 误判 | 真相 | 纠正 |
|---|---|---|
| 「不漏水」是兴奋型 | 基本型，缺失必差评 | 看 `missing_bad_rate`，>0.30 即基本型 |
| 「颜色好看」是期望型 | 多为无差异型 | `improvable_score` 常 ≤3，直接 P2 |
| 「赠品收纳袋」是基本型 | 提及率 <15%，兴奋型 | 看 `satisfied_rate` <0.20 + 强度 ≥4 |
| 频次第一就是 P0 | 可能是不可改进项 | 加可改进性 ≥6 硬门槛 |
| 付费意愿看竞品均价 | 均价不反映溢价意愿 | 用 `spread_ratio` + 文本 + 替代品三路 |
