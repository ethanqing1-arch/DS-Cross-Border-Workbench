# FBA 配送费分段（`fba_fee_usd` 取值口径）

本表用于给 `profit-model` 提供 `fba_fee_usd`。费率每年调整，**下单前必须在卖家后台"费用预览"核对一次**；本表是取数起点，不是最终依据。

## 1. 先判尺寸分段（美国站，英寸/磅为后台口径，此处给 cm/g 换算阈值）

| 分段 | 尺寸上限 | 重量上限 | 判定 |
|---|---|---|---|
| 小号标准 | 38.1 × 30.5 × 1.9 cm | 453 g（16 oz） | 三条边全满足才算 |
| 大号标准 | 45.7 × 35.6 × 20.3 cm | 9.07 kg（20 lb） | 三条边全满足才算 |
| 大件 | 超过大号标准 | 分档见后台 | 家居、家具、大件器械 |
| 特殊大件 | 最长边 > 274 cm 或围长 > 419 cm | — | 不走 FBA，改海外仓 |

判定顺序：先看最长边 → 再看次长边 → 再看最短边 → 最后看重量。**任何一条超限就降到下一段**，不要只看重量。

## 3. 大件（只给取值方法，不给单价）

大件费率 = 基础费 + 单件重量费 + 尺寸附加。取值三步：

1. 后台"费用预览"输入实测尺寸重量，直接读 `配送费`。
2. 无后台权限时用官方费率卡（FBA Fulfillment Fees，按分段表）手算，标 `[C]`。
3. 大件品一律在报告里注明"FBA 费率为估算，实际以后台为准"。

## 4. 降段动作（省的是纯利润）

| 现象 | 动作 | 常见收益 |
|---|---|---|
| 最短边 2.1 cm，卡在小号标准线外 | 改平底包装、去内衬，压到 ≤ 1.9 cm | 每件省 0.3–0.6 USD |
| 重量 470 g，卡在 453 g 线外 | 减配件、改薄壁、抽真空 | 每件省 0.4–0.9 USD |
| 体积重超标（泡货） | 拆件分箱、缩短杆件 | 省体积费，降一段 |
| 大件但可折叠 | 折叠款重新量尺寸，可能回到大号标准 | 每件省 3–8 USD |

## 5. 与本包其他字段的联动

- `fba_fee_usd` 影响 `平台与履约`，进而影响 `贡献利润` 与红线 2、3。
- 判完分段后，`inbound_usd` 也要同步按新体积重算一次（体积重 = 长×宽×高/6000，单位 cm→kg）。
- 敏感性分析里不改 `fba_fee_usd`；若要评估"降段"收益，单独加一行 `包装优化情景`，并在报告注明是结构改动而非价格波动。

## 4. 取数优先级（别抄网文）

| 级别 | 来源 | 说明 |
|---|---|---|
| A | SP-API `getMyFeesEstimate` / `getMyFeesEstimates`（Product Fees API） | 传 ASIN + 售价，返回佣金 + FBA 配送费 + 其他费用明细，**唯一权威** |
| B | 卖家后台「费用预览」/ 收入计算器 | 手工核单个 ASIN |
| C | 官方 rate card（当年版）+ 本表 | 批量估算，须把版本号（如 `US-2026-01`）写进 `run_meta.json` |
| D | 凭经验填 | 只用于建模占位，报告里必须标 `[D]` |

## 5. 最容易漏的四项

| 项 | 口径 | 常见值 |
|---|---|---|
| 入库配置费（Inbound Placement） | 按分仓方案 / 件 | 0.1–0.8 USD，合仓更贵 |
| 仓储费（含旺季 10–12 月 3 倍、长期库存附加费） | 按月均库存体积 | 淡旺季差 3 倍，压货会吃掉利润 |
| 退货处理费 | 部分类目按退货率收 | 服装/鞋高，家居低 |
| 移除/弃置费 | 按件 | 清仓款退出成本，做决策时就要算 |

把包装重量压到下一档，是最便宜的降本手段——`profit-model` 的敏感性分析要专门测这一项。
