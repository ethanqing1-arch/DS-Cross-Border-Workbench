# 视觉策略：把主图当转化率工具，不是审美题

## 何时用

1. 新品上线前，要把「差异化命题」翻译成 7 张图和 1 条视频的分镜。
2. 点击率低于类目均值，需要判断是主图问题还是价格问题。
3. 对手主图全是白底摆拍，想用场景图或对比图抢点击。
4. 副图信息堆成说明书，移动端缩略后什么都看不清。
5. A+ 模块顺序乱，首屏放品牌故事浪费流量。
6. 视频已拍但前 3 秒没人看，需要重剪开头。

不归这里：卖点桶饱和度看 `competitor-deconstruct`；差异化命题与 BOM 看 `negative-review-gap`；五点与标题文案由文案执行方落地，合规审查走 `compliance-gate`。本 skill 只决定「画面说什么、按什么顺序说」。

## 输入契约

| 字段 | 来源 | 缺失时怎么办 |
|---|---|---|
| `target_asins` | 3–8 个对标 ASIN | 必需 |
| `competitor_images` | 每个 ASIN 主图 + 6 副图 + A+ 截图 + 视频链接 | 必需。无 A+ 的 ASIN 该维度记「无」 |
| `cmp_claim_saturation` | `competitor-deconstruct` | 缺失时按经验把「材质」当红海处理，标 `[D]` |
| `cmp_diff_claim` | `negative-review-gap` 的 `cmp_diff_claim` | 缺失时视觉只能做「跟随型」，不得自称差异化 |
| `review_scene_words` | 1–5 星评论中出现的场景词频（如 kitchen/gym/car/office/travel） | 缺失时用搜索词里的场景词替代，标 `[C]` |
| `cvr_target` | 类目转化率均值 | 缺失时用 `market-sizing` 价格带 CVR 表 |

## 执行流程

1. **定 1 个视觉主命题**：取 `cmp_diff_claim` 作为主图与副图第 1 张的唯一信息点；没有命题时，只能做「跟随型视觉」，明写「无差异化主张」。
2. **排 7 图槽位**（顺序固定，不允许调换 P1/P2）：P1 白底主图、P2 结构/功能分解、P3 场景图、P4 对比图、P5 尺寸标注、P6 使用步骤、P7 清单与售后。
3. **写 P1 约束**：纯白底 RGB(255,255,255)、产品占画面 80%–88%、无文字/无 Logo 水印/无道具（配件属于产品本身可保留）、投影允许柔和但不得形成第二主体。
4. **做缩略图体检**：把 P1 缩到 200×200 px，检查主体轮廓是否可辨、关键线条是否 ≥2 px；不可辨则放大产品或加轮廓光。
5. **写 P2–P7 单点信息**：每张只承载 1 个信息点，标题 ≤7 个英文词，正文 ≤3 行，文字面积 ≤12% 画面（移动端 ≤8%）。
6. **选场景**：取 `review_scene_words` 前 3 个场景，P3 只放 1 个最高频场景，其余场景进 A+；场景图必须出现人手或使用动作。
7. **做对比图**：P4 用「本品 vs 普通款」两栏，禁止出现竞品品牌名与竞品图；对比维度只取 1 个（结构强度/容量/耗时）。
8. **写尺寸标注**：P5 同画面标 in 与 cm 双单位，标注线不遮挡产品主体，尺寸数字 ≥画面宽度的 4%。
9. **排 A+ 节奏**：5–7 模块，首屏必须是 M1 主视觉或 M2 对比表；品牌故事仅在已有品牌认知时放，且不得占首屏。
10. **定视频钩子**：首 3 秒三选一——痛点演示（东西坏了/装不上）、结果前置（成品效果）、对比（普通款失败 vs 本品成功）；3 秒内必须出现产品实物，前 3 秒禁 Logo 开场、禁片头字幕。
11. **算视觉差距**：按「视觉差距表」8 个维度给对手与我方各打 0–5 分，算 `cmp_visual_gap = (对手均分 − 我方均分) / 5`。
12. **落盘**：`主图brief.md`（7 张逐张 brief）+ `视觉差距表.csv` + `视觉策略.md`（结论行→差距表→brief 摘要→动作）。

算例（真实量级）：对手 8 维均分 4.1，我方 2.6 → `cmp_visual_gap = (4.1−2.6)/5 = 0.30` → 差距主要在「场景图」（0/5）、「对比图」（1/5）、「尺寸标注」（1/5）；结论：先补 P3/P4/P5 三张，预计点击率提升 15%–25%，验收 = 上线 14 天 CTR 从 0.42% 到 0.50%。

## 判定口径

| 指标 | 阈值 | 判定 |
|---|---|---|
| P1 背景 | RGB 非 (255,255,255) | 违规，重拍或抠图重做 |
| P1 产品占比 | < 70% | 太小，缩略不可辨 |
| P1 产品占比 | 80%–88% | 合格 |
| P1 产品占比 | > 92% | 有裁切风险，留 5% 边距 |
| P1 文字 | 任何文字/水印/Logo 叠加 | 违规（Amazon 主图禁） |
| 缩略可辨 | 200×200 px 下关键线条 < 2 px | 不可辨，重做 |
| 副图文字面积 | > 12% | 过载，移动端看不清 |
| 副图信息点 | 单图 > 1 个信息点 | 拆分或删减 |
| 副图标题词数 | > 7 个英文词 | 截断，重写 |
| 场景图数量 | 2 张 | 上限（再多挤掉功能信息） |
| 场景图 | 无人物/无使用动作 | 不算场景图，算摆拍 |
| 对比图 | 出现竞品品牌名或竞品图 | 违规，改「普通款」示意 |
| 尺寸标注 | 无双单位（in + cm） | 补 cm，海外用户退货主因之一 |
| A+ 模块数 | < 5 | 信息不足 |
| A+ 模块数 | 5–7 | 合格 |
| A+ 模块数 | > 9 | 用户滑不到底，砍到 7 |
| A+ 首屏 | 品牌故事 / 纯 Logo | 首屏浪费，换 M1 或 M2 |
| 视频首 3 秒 | Logo 开场 / 无产品 | 重剪 |
| 视频时长 | < 20 秒 | 信息不足；建议 30–45 秒 |
| 视频完播率 | < 25% | 钩子失败，重剪前 3 秒 |
| 图内最小字号 | 移动端缩略后 < 18 px（等效） | 不可读，放大或删字 |
| P4 对比维度 | > 1 个 | 拆图；一张图只比一项 |
| `cmp_visual_gap` | ≤ 0.10 | 视觉不构成劣势 |
| `cmp_visual_gap` | 0.10–0.30 | 需补 2–3 张图 |
| `cmp_visual_gap` | > 0.30 | 视觉是主要短板，优先于文案投入 |

## 输出契约

- 落盘：`out/<run_id>/视觉策略.md`、`out/<run_id>/主图brief.md`、`out/<run_id>/视觉差距表.csv`。
- CSV 列：字典字段逐字一致 → `sku, category, product`；扩展列 → `cmp_asin, cmp_visual_dim, cmp_score_comp, cmp_score_self, cmp_visual_gap, cmp_main_image_formula, cmp_scene_top1, cmp_aplus_modules, cmp_video_hook`。
- `主图brief.md` 每张图固定 6 行：`槽位 / 目标（提升哪个指标）/ 画面（构图与占比）/ 文案（≤7 词）/ 证据（数字或测试）/ 约束（合规与像素）`。
- 正文五段：**结论行 → 视觉差距表 → 7 图 brief 摘要 → 视频钩子 → 动作**。
- 结论行：`结论：视觉差距 {值}（{档}），最缺 {槽位}，主命题「{一句话}」，预计 CTR {区间} [B]`

跨层交接字段：

| 字段 | 消费层 | 用途 |
|---|---|---|
| `cmp_main_image_formula` | 06-delivery `deck-report`、广告执行方 | 主图公式复用到广告素材与提案 |
| `cmp_visual_gap` | `market-entry`（回写） | 差距 >0.30 时进入难度分中「评论壁垒」放宽一档，由主控人工回校 |
| `cmp_scene_top1` | `amz-keyword-harvest`、广告投放 | 场景词进标题与手动广告组 |
| `cmp_aplus_modules` | 文案执行方、`compliance-gate` | A+ 搭建顺序直接照排 |
| `cmp_video_hook` | 06-delivery、广告执行方 | 视频素材复用，避免二次创作 |

## 质检清单

- [ ] 7 个槽位齐全，P1/P2 顺序未被调换。
- [ ] P1 三条硬约束（纯白/占比/无文字）都有实测值，不是"应该没问题"。
- [ ] 做过 200×200 px 缩略体检并记录结论。
- [ ] 每张副图只承载 1 个信息点，标题词数逐张可查。
- [ ] 对比图无竞品品牌名与竞品图。
- [ ] 尺寸标注双单位，数字字号已核。
- [ ] A+ 首屏是 M1 或 M2，模块数 5–7。
- [ ] 视频首 3 秒有明确钩子类型与产品出现时间点。
- [ ] 视觉差距表 8 维逐项打分，双方同口径。
- [ ] 数据可信度声明：图片评分为人工判断标 `[C]`，CTR 预测标 `[C]` 或 `[D]`。

## 反模式

1. **把主图当海报**。错误：加 3 行英文卖点 + 角标。正确：P1 只有产品和纯白底，卖点搬去 P2 与五点。
2. **副图当说明书**。错误：一张图放 5 个箭头 + 8 行字。正确：一图一点，文字面积 ≤12%。
3. **场景图摆拍无人**。正确：必须有人手/使用动作，否则不算场景图。
4. **对比图点名竞品**。正确：改「普通款 vs 本品」，用示意图不用实拍对手。
5. **视频靠 Logo 开场**。正确：前 3 秒给痛点或结果，Logo 放结尾 5 秒。
