# 准入闸、骨架模板与上线清单（`skill-creator`）

## 1. 6 问准入闸：怎么取证

| # | 问题 | 取证方式 | 通过 | 不通过 |
|---|---|---|---|---|
| 1 | 重复 ≥ 3 次 | 工单系统按意图去重计数（30 天）；同一天同一意图只算 1 次 | ≥ 3 | < 3 → 写一次性 prompt |
| 2 | 输入稳定 | 把最近 3 次人工流程的输入字段列出来，字段重合 ≥ 80% | 稳定 | 每次字段都变 → 先固化表单 |
| 3 | 输出可判定 | 能否写出 ≥ 5 个带单位阈值，或三态结论 | 能 | 只能写"看着办" → 不建 |
| 4 | 需要外部数据 | 判断是否依赖平台/工具；依赖就必须写取数口径 + 失败降级 | 已写 | 只写"去查一下" → 返工 |
| 5 | 已被覆盖 | `grep -ril "<核心动词>" skills/*/*/SKILL.md`；比触发词与 outputs | 无重叠或 < 50% | > 50% → 加一节 |
| 6 | 失败成本 | 失败会不会赔钱/赔账号/赔时间：赔钱与赔账号=高，返工半天=中，多打一行=低 | 中/高 | 低 + 高频 → checklist |

结论映射：

| 组合 | 结论 |
|---|---|
| 1 通过 + 2 通过 + 3 通过 + 5 无覆盖 | 建 skill |
| 1 通过 + 5 有覆盖（> 50%） | 加到已有 skill 的一节 |
| 1 不通过 | 不建，写 prompt 或便签 |
| 3 不通过 | 不建，先把阈值定下来 |
| 2 不通过 | 不建，先把输入表单固化 |

## 3. 3 个回归 case 的取法

| case | 类型 | 要求 | 判定 |
|---|---|---|---|
| C1 | 正常 | 字段齐全、结论明确 | 输出与预期档位一致 |
| C2 | 边界 | 缺 1–2 个必需字段 | 走降级路径，结论降档且写明缺什么 |
| C3 | 反例 | 不该触发本 skill 的输入 | 明确说"不归这里 → 去 X"，不硬给结论 |

`回归记录.md` 表：

| case_id | 输入摘要 | 预期结论 | 实际结论 | 一致? | 差异点 | 修的哪一节 |
|---|---|---|---|---|---|---|
| C1 | 水杯全字段 | 小批量观察 59.5 | 小批量观察 59.5 | 是 | — | — |
| C2 | 缺 `cogs_cny` | 补充数据 | 补充数据 | 是 | — | — |
| C3 | 让算店铺 GMV | 不归这里→ecom-ops | 不归这里→ecom-ops | 是 | — | — |

3/3 一致才可上线；2/3 时只允许改判定口径或执行流程，不许改 case 让结果变好看。

## 4. 上线清单

| 检查项 | 阈值 | 校验命令/方式 |
|---|---|---|
| frontmatter 字段 | 8 个全有 | `sed -n '1,10p' SKILL.md` 人工核 |
| `name` 格式 | 小写连字符、无层前缀、全局唯一 | `ls skills/*/*/SKILL.md \| xargs grep -h '^name:'` 查重 |
| 主文件行数 | 120–220 | `wc -l < SKILL.md` |
| 小节数 | 7 个 | `grep -c '^## '` |
| 判定口径数字 | ≥ 5 个带单位阈值 | 人工数表行 |
| 占位符 | 0 命中 | `grep -nE 'T[O]DO|x{3}|待[补]充'` |
| 上下游互链 | 双向 | 在上下游文件里 grep 本 skill 名 |
| 回归 | 3/3 一致 | `回归记录.md` |
| 版本号 | 语义化，首次 1.0.0 | 人工核 |

一键自检脚本：

```bash
for f in skills/*/*/SKILL.md; do
  n=$(wc -l < "$f"); s=$(grep -c '^## ' "$f"); ph=$(grep -cE 'T[O]DO|x{3}|待[补]充' "$f")
  echo "$f lines=$n sections=$s placeholders=$ph"
done
```

判定：`120 ≤ lines ≤ 220`、`sections == 7`、`placeholders == 0`，三条同时成立才算过。

## 5. 版本与变更记录

| 变更 | 版本 |
|---|---|
| 首次上线 | 1.0.0 |
| 加判定项、不改既有阈值 | 1.1.0 |
| 改阈值或权重（须先改 SPEC） | 2.0.0 |
| 修错别字、调格式 | 1.0.1 |

改阈值前必须先改 `SKILL_SPEC.md` 第 4 节；SPEC 没改而 skill 先行，视为偏离，退回。
