# 场景卡模板与需求参数映射

供 `jtbd-map` 步骤 3–8 与 `05-product/decision-control` 直接使用。所有数字为真实量级示例，可照抄格式。

## 1. 单卡模板（照抄结构）

```markdown
### SC-01 小厨房台面备菜

| 项 | 内容 |
|---|---|
| 谁 | 租住 45㎡ 公寓的两人家庭，台面 60cm，每周做饭 4 次 |
| 情境 | 工作日晚 18:30–19:30 备菜，台面同时放砧板与两口锅 |
| 任务陈述 | 当我只有 60cm 台面要处理 3 种食材时，我想要一个能折叠收纳、不占台面的备菜容器，这样我就能一次备完，而不必把菜堆在水槽里或反复挪锅 |
| 现用方案 | 塑料盆（IKEA 365+）、砧板边缘、外卖盒 |
| 失败点 1 | 盆底无防滑，切菜时移位 → 对应 PP-02 |
| 失败点 2 | 不可折叠，收纳占 1/3 橱柜 → 对应 PP-04 |
| 失败点 3 | 边缘低，汁水外流到台面 → 对应 PP-01 |
| 证据（3 条） | 「my cutting board slides all over the counter」4★ 2025-03-12 ASIN B0CQ7X2M9L；r/Cooking 2025-04-02 帖「Best compact cutting board for small kitchens?」；Q&A 2025-02-18「does it fold flat?」 |
| 产品需求 | 结构：底部硅胶防滑 + 可折叠侧壁 |
| 参数目标 | 展开 38×28×9cm，折叠后高 ≤3.5cm；防滑系数 ≥0.6；侧壁高 9cm |
| 优先级 | P0（覆盖 PP-01/PP-02/PP-04 三个 P0 痛点） |
```

## 2. 需求 → 参数映射表（五类）

| 需求类型 | 常见失败点 | 参数写法示例 | 验收方法 |
|---|---|---|---|
| 结构 | 铰链裂、卡扣松、折叠不顺 | 开合 10000 次无裂；壁厚 ≥2.0mm；卡扣保持力 ≥15N | 打样循环测试 + 拉力计 |
| 材质 | 生锈、涂层脱落、异味 | 304 不锈钢；盐雾 48h 无锈；涂层附着力 ≥4B | 盐雾箱 + 百格刀 |
| 尺寸 | 放不进、装太少、公差大 | 内径 200±1mm；容量 1.8L；折叠高 35mm | 卡尺 + 量杯 |
| 包装 | 运输破损、缺件 | 单件跌落 1.2m 六面各 1 次无破损；内衬 EPE 5mm | 跌落测试 |
| 说明 | 装错、不会用、退货 | 图示步骤 ≤6 步；零件编号 1–8；含二维码视频 | 用户测试 5 人，0 次装错 |

## 3. 场景维度组合表（用于步骤 2 聚场景）

| 维度 | 取值（按品类替换） |
|---|---|
| 人群 | 单身 / 两人 / 有幼儿 / 有宠物 / 老人 / 合租 |
| 空间 | 小厨房（台面 <80cm）/ 普通厨房 / 房车 / 宿舍 / 户外 |
| 事件 | 日常备菜 / 批量备餐 / 请客 / 露营 / 搬家 / 清洁 |
| 动作 | 收纳 / 携带 / 组装 / 清洗 / 长期存放 |

组合优先级：`人群 × 空间` 先组合（证据最多），再叠事件。

## 4. 证据引用规范

每条证据必须含四项：

1. 原文（英文原样，不改写）；
2. 星级或来源类型（`4★` / `reddit` / `qa`）；
3. 日期（`YYYY-MM-DD`）；
4. ASIN 或帖子链接。

缺任一项 → 该条不计入 `evidence_count`。

## 5. 与下游的接口

| 下游 | 取哪些字段 | 用途 |
|---|---|---|
| `05-product/decision-control` | `who`/`situation`/`job_statement`/`product_requirement`/`parameter_target` | 决策卡的场景章与规格章 |
| `05-product/profit-model` | `parameter_target` 里影响成本的项 | 算 `cost_delta_usd` |
| `04-competitor/visual-strategy` | `situation` + `failure_point` | 主图场景选择与五点前两条 |
| `05-product/decision-control` | `scenario_priority` 分布 | 差异化维度打分参考 |

## 6. 常见场景判定错误

| 错误 | 表现 | 纠正 |
|---|---|---|
| 场景即人群 | 「宝妈」算一张卡 | 加空间与事件，拆成「带 2 岁幼儿、小厨房、每日辅食」 |
| 场景即品类 | 「厨房用品」 | 必须到动作与结果 |
| 失败点无锚 | 失败点找不到 pain_point_id | 回 `voc-mining` 补簇，或删除该失败点 |
| 需求无参数 | 「更好用」 | 改成可测数字，否则退回 |
| 卡片过多 | 12 张 | 按 `evidence_count × priority` 取前 7 |
