## 2. 五路分项打分算法

```python
S1 = clip((top10_share - 0.25) / 0.55 * 100, 0, 100)
S2 = clip(log10(1 + min_page_review) / log10(3001) * 100, 0, 100)
S3 = clip((cpc / cvr / contribution_profit) / 0.8 * 100, 0, 100)
S4 = clip((1.5 - gap_max) / 1.0 * 100, 0, 100)
S5 = clip((20 - new_share_pct) / 20 * 100, 0, 100)
entry_score = 0.25*S1 + 0.25*S2 + 0.20*S3 + 0.15*S4 + 0.15*S5
```

`clip(x, 0, 100)` = 低于 0 取 0，高于 100 取 100。

## 4. 四档含义与动作

| 档 | 分数 | 动作 | 首月预算 |
|---|---|---|---|
| 易 | ≤ 30 | 直接小批量测试 100–200 件 | $1,500–3,000 |
| 中 | 31–55 | 先做 1 个改款点再测 100 件 | $3,000–6,000 |
| 难 | 56–75 | 必须有功能错位 + 供应链成本优势，否则放弃 | $6,000–12,000 |
| 极难 | > 75 | 不进。除非有独家专利或工厂独家模具 | 0 |

## 5. 广告预算上限推算

```
首月广告预算上限 = SOM 首月销售额 × ad_share 上限
SOM 首月销售额   = mkt_som_usd / 12
ad_share 上限    = min(0.35, ad_burden × 0.5)
```

`ad_burden > 0.5` 时 `ad_share` 上限被压到 0.25，说明广告效率不够，需先做 Listing 转化率优化或换价格带。
