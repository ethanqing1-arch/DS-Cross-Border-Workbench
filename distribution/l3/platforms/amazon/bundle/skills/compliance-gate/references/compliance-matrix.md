# 合规核查底稿（`compliance-gate`）

## 1. 侵权四查操作手册

### 1.1 商标（查 15 分钟）

| 步 | 动作 | 记录 |
|---|---|---|
| 1 | 打开 `tmsearch.uspto.gov`，选 Basic 检索 | 检索词 + 日期 |
| 2 | 输入产品核心词（英文）、竞品品牌名各查一次 | 结果条数 |
| 3 | 看尼斯分类是否落在 9/11/21/28/20 等重叠类 | 注册号 + 类目 + 状态（LIVE/DEAD） |
| 4 | 在 Amazon 前台搜该品牌，看是否 Brand Registry、是否卖同类 | 截图 |
| 5 | 判定：同类别有 LIVE 注册 → 商标命中 +5 | 写入 `trademark_hit` |

只查 DEAD 标 → 不算命中；标在完全不同类目 → 不算命中，但要记"跨类扩张风险"。

### 1.2 专利（查 25 分钟）

| 步 | 动作 | 记录 |
|---|---|---|
| 1 | `patents.google.com` 搜 `<英文品名> design`，筛"美国" | 候选 D 号 |
| 2 | 再搜 `<英文品名> utility`，筛近 5 年 | 候选实用专利 |
| 3 | 取最像的 1–3 个，抄专利号、优先权日、附图 | 专利号 |
| 4 | 读权利要求第 1 条，看是否覆盖核心结构/机构 | 关键限定词 |
| 5 | 判定：外观 ≥ 3 特征重合 → +6；2 特征 → +3 | 写入 `patent_hit` |

外观专利保护期 15 年（2013 年后申请），实用专利 20 年。过期专利可自由做，但要记"过期日"。

### 1.3 版权（查 10 分钟）

对主图、印花、包装插画做 Google 图片反搜（`images.google.com`）。命中下列任一即 `+8`：卡通/动漫形象、影视角色、球队与联赛 logo、名画与博物馆藏品、知名 IP 字体设计。
版权项**不给整改空间**（改一版仍可能侵权），直接判"不可上"。

### 1.4 外观近似比对（4 特征）

| 特征 | 比什么 | 记几成 |
|---|---|---|
| 整体轮廓 | 长宽比、圆角半径、收腰位置 | 0/0.5/1 |
| 分割比例 | 上下体比例、盖体高度比 | 0/0.5/1 |
| 关键装饰 | 纹理、开孔排列、logo 位置 | 0/0.5/1 |
| 功能开口 | 出水口、按键、接口位置 | 0/0.5/1 |

合计 ≥ 3 成 → 外观命中 (+6)；= 2 成 → 可能命中 (+3)，标"律师复核"。

## 2. 认证矩阵（按产品特征取并集）

| 产品特征 | US | EU | 谁出 | 周期 | 费用区间 USD |
|---|---|---|---|---|---|
| 无线/蓝牙/WiFi | FCC ID | CE-RED | 第三方实验室 | 5–15 天 | 300–1,200 |
| 普通电子（无无线） | FCC SDoC | CE-EMC | 第三方 | 5–10 天 | 200–600 |
| 市电/加热/大功率 | UL 或 ETL | CE-LVD | NRTL | 3–8 周 | 1,500–6,000 |
| 12 岁以下儿童 | CPC | CE-EN71 | 第三方 + 证书 | 7–20 天 | 400–1,500 |
| 含锂电 | UN38.3 + MSDS + 鉴定 | 同 | 电池实验室 | 7–15 天 | 250–800 |
| 液体/粉末/化学品 | MSDS(SDS) | REACH | 第三方 | 3–7 天 | 120–400 |
| 食品接触 | FDA 声明 | LFGB | 第三方 | 5–10 天 | 200–700 |
| 化妆品/护肤 | FDA 设施注册 + 成分 | CPNP | 合规代理 | 2–6 周 | 500–2,000 |
| 医疗器械 | 510(k) / 列名 | CE-MDR | 法规顾问 | 3–9 个月 | 8,000–40,000 |
| 杀虫/驱虫/抗菌宣称 | EPA 注册 | BPR | 法规代理 | 6–18 个月 | 15,000+ |
| 复合木/板材 | CARB P2 / TSCA VI | E1 | 供应商 + 检测 | 2–4 周 | 300–900 |
| 加州销售（含化学物） | Prop 65 警示标签 | — | 自查 + 标签 | 1 天 | 0 |
| 激光产品 | FDA 激光报告 | CE | 第三方 | 1–3 周 | 400–1,200 |

判定规则：`cert_required = 1` 当且仅当"本行命中且卖家无该资质"。

## 3. 危险品与带电细分

| 情形 | UN 编号/条款 | 空运 | 海运 | FBA |
|---|---|---|---|---|
| 内置锂电 ≤ 100 Wh | UN3481 / PI967 Sec II | 可 | 可 | 需危险品审核 |
| 随货配套锂电 | UN3481 / PI966 | 可 | 可 | 需审核 |
| 单独锂电芯/电池 | UN3480 / PI965 | 多数拒收 | 可 | 需审核 |
| 液体 > 100 mL | — | 限运 | 可 | 需 MSDS |
| 气雾罐 | UN1950 | 不可 | 可 | 多数禁 |
| 强磁 | UN2807 | 需磁检 | 可 | 需屏蔽包装 |
| 打火机/易燃 | UN1057 等 | 不可 | 受限 | 禁 |
| 刀/管制器具 | — | 可运 | 可运 | 平台限售 |

判"不可空运" → `inbound_usd` 按海运重算（通常 1.2–2.5 USD/kg），并在报告标"头程约束"。

## 4. 类目限制清单（无资质直接不可上）

| 类目 | 门槛 | 判定 |
|---|---|---|
| 食品/饮料/保健品 | FDA 设施注册 + 成分合规 + 保质期 | 无注册 → 不可上 |
| 化妆品/护肤/彩妆 | FDA 注册 + 成分 + 宣称合规 | 无注册 → 不可上 |
| 医疗器械/矫正/理疗 | 510(k) 或列名 | 无 → 不可上 |
| 杀虫/驱虫/抗菌/消毒宣称 | EPA 注册 | 无 → 不可上 |
| 婴儿配方/辅食 | FDA 严格 | 无 → 不可上 |
| 激光/强光 | FDA 激光报告 | 无 → 不可上 |
| 电池独立销售 | UN38.3 + 平台审核 | 无 → 不可上 |
| 二手/翻新 | 平台类目准入 | 无 → 不可上 |
| 酒精/烟草/电子烟 | 平台禁售或严审 | 无 → 不可上 |

注意：**"抗菌""杀菌""防霉"这类词本身就是宣称**，普通家居品写了就变成 EPA 管辖，改文案比补注册便宜。

## 5. 市场合规（多站点才做）

| 项 | 适用 | 动作 |
|---|---|---|
| 德国包装法 VerpackG | 发德国 | 注册 LUCID，取得包装注册号，平台要填 |
| 法国 EPR | 发法国 | 注册 UIN（包装/电子/家具分品类） |
| 意大利/西班牙 EPR | 发对应国 | 通过合规服务商注册 |
| 美国各州包装 EPR | 加州/俄勒冈/缅因/科罗拉多/明尼苏达 | 关注生效时间，年销超门槛需注册 |
| VAT | 欧盟仓储 | 有仓储即需当地 VAT 号，OSS/IOSS 申报 |
| 英国 UKCA/UKCA 过渡 | 发英国 | 按现行规则贴标 |
| 加州 Prop 65 | 含化学物 | 加警示标签，否则集体诉讼风险 |

## 6. 整改清单模板（每条 = 谁 + 做什么 + 几天 + 验收物）

| # | 问题 | 谁做 | 动作 | 工期 | 验收物 |
|---|---|---|---|---|---|
| 1 | 图案疑似某 IP 风格 | 卖家 | 换原创图案，重出主图 | 5 天 | 新主图 + 设计源文件 |
| 2 | 外观 2 特征重合 | 卖家 | 请律师出 FTO 简版意见 | 7 天 | 意见书（书面） |
| 3 | 无 FCC | 工厂 + 实验室 | 送样做 FCC SDoC | 10 天 | 报告编号 |
| 4 | 含锂电无 UN38.3 | 电池厂 | 出 UN38.3 + MSDS | 12 天 | 报告 + 鉴定书 |
| 5 | 包装未注册 LUCID | 卖家 | 注册并回填平台 | 3 天 | 注册号截图 |
| 6 | 宣称"抗菌" | 卖家 | 删词改文案 | 1 天 | 改后 listing 截图 |

验收口径：整改项全部闭环 + 复检 `ip_risk ≤ 3` 且 `cert_required = 0`，才可从"需整改"升到"可上"。
