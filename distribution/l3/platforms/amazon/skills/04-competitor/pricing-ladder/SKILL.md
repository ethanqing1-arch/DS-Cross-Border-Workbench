# 价格带阶梯：把定价值成一道算术题

## 何时用

1. 产品做出来了，不知道挂 $19.99 还是 $27.99。
2. 判断哪一档「买的人多但卖家少」，作为定价切入点。
3. 已在卖，想验证能不能涨价 8%，怕销量掉。
4. 对手突然全线降 15%，要判断是跟价还是守价。
5. 给 `market-entry` 的「价格错位」姿势提供可行性数据。
6. 给 `profit-model` 反推「最低可售价」（红线约束下的价格下限）。

不归这里：市场总量看 `market-sizing`；进入难度总分看 `market-entry`；促销节奏看 `competitor-deconstruct`；改款后成本重算看 `profit-model`。本 skill **不碰** 第 4.1 节红线，只保证定价落在红线之上。

## 输入契约

| 字段 | 来源 | 缺失时怎么办 |
|---|---|---|
| `top100_price_sales` | 可比 ASIN 的同口径报价 + `est_monthly_sales` | 缺销量时仅做价格分布，供需缺口留空。销量列取自 `market-sizing` |
| `top_review_count` | 逐 ASIN 评论数 | 必需 |
| `rating` | 逐 ASIN 星级 | 缺失时该档「平均评分」列写 `n/a`，不参与判定 |
| `listing_age_months` | 逐 ASIN 上架月龄 | 缺失时新品数按评论数 < 50 替代，标 `[C]` |
| `cpc_usd` | 广告实测 CPC | 缺失取 `$0.85`，标 `[C]` |
| `contribution_profit_usd` | 05 层模型在候选价下的贡献利润 | 必需；用于校验锚点是否在红线之上 |
| `mkt_gap_band` | `market-entry` 的空位档 | 缺失时自行算 `gap`，与 `market-entry` 不一致以本 skill 为准并回写 |

## 执行流程

1. **清洗并装桶**：先限定同站、同配送地、同兼容规格、同装量和自然位，按有效变体 ASIN 去重。只用一种报价基准：有成交证据用实付，否则标列表价。排除无价、整机、混装套件、标称装量与实际主件数冲突的样本。每单位价 = 包价 ÷ 确认的主件数，配件不进分母。再按可比报价装 5 档。默认固定档 `0/15/25/45/80/∞` USD；若价格分布偏斜 `|skew| > 1.5` 或任一固定档 listing < 5，切分位点模式（20/40/60/80 分位），并在报告写「分档模式：分位点」。
2. **逐档算 7 个指标**：`listing 数`、`销量占比`、`供给占比`、`均价`、`平均评论数`、`平均评分`、`新品数（<12 个月）`。
3. **算供需缺口**：`gap = 销量占比 / 供给占比`。
4. **算可比样本评论中位数**：取同一可比组最终纳入的 ASIN 评论数中位，作为评论壁垒基准。
5. **找高需求低供给档**：同时满足 ① `gap ≥ 1.5` ② 档内平均评论数 < 可比组中位数 × 0.8 ③ 新品数 ≥ 3。三条全中才标「目标档」。
6. **算价格锚点**：`锚点 = 目标档中位价 × (0.95–1.05)`，再收敛到心理价位（`.99` / `.95` / `.49`，取离锚点最近的）。
7. **红线校验**：把锚点代入 05 层模型，必须同时满足 毛利率 ≥ 30%、贡献利润率 ≥ 8%、贡献利润 ≥ $3；不满足则上移到满足的最低 `.99` 价，并记录「价格已被红线顶高」。用同规格样本中位数和 P25–P75 对照最低可售价。最低价单列。成本线高于 P75 只写「高于样本主流带，待核」，同规格样本少于 3 条只写「样本不足」。跨装量单位价折算只作情景。
8. **算价格下限**：分别反解毛利率 30%、贡献率 8% 和单件贡献 3 USD 等值的最低价，取三者最大值并向上取到可报价单位。
9. **设计三段测试**：获准测试后，A = 锚点、B = 锚点 × 0.92、C = 锚点 × 1.08。逐一过价格下限，每段连续 14 天，段间不重叠，一次只动价格（不动主图/广告/ coupon）。

测试执行纪律（违反任一条，该段数据作废）：

| 纪律 | 要求 |
|---|---|
| 单变量 | 段内不改主图、不改广告预算、不加 coupon、不改标题 |
| 库存 | 每段开始前库存 ≥ 该段预计销量 × 1.5，断货即作废 |
| 记录 | 每日记录价格、单量、会话数、BSR、Buy Box 归属 |
| 止损 | C 段单量跌 > 40% 且连续 3 天，立即回 A，判「不可涨」 |
| 回滚 | 测试结束 24 小时内回到锚点，不留残余价签 |

10. **算样本门槛**：每段最低订单数 60 单；`日均单量 × 14 < 60` 时延长到 21 天或改用 A/B 两段。
11. **算弹性**：`e = [(Q2−Q1)/((Q1+Q2)/2)] ÷ [(P2−P1)/((P1+P2)/2)]`，用 A 与 C 两段数据。
12. **给涨价结论**：按「判定口径」的 `|e|` 分档给结论，并算出涨价后的贡献利润变化（含销量下降）。
13. **落盘**：`价格阶梯.csv`（5 行档位 + 逐 ASIN 明细表另存）+ `价格阶梯.md`（结论行→阶梯表→目标档→锚点与测试→动作）。

算例（真实量级）：5 档中 `$25–45` 档销量占比 41%、供给占比 24% → `gap = 1.71`；该档平均评论 216，可比组中位数 380（`216 < 304` 成立）；新品数 6 → 三条全中，目标档成立。中位价 `$32.99` → 锚点 `$32.99`；红线校验：贡献利润 $6.8、利润率 20.6% 通过。测试：A $32.99 / B $30.35 / C $35.63，各 14 天。C 段日均从 9.2 单降到 7.8 单 → `e = −0.83` → `|e| < 1.0` → 可涨，涨后贡献利润月增 $412。

## 判定口径

| 指标 | 阈值 | 判定 |
|---|---|---|
| 分档模式 | `\|skew\| > 1.5` 或任一档 < 5 个 | 切分位点模式 |
| `gap` | ≥ 1.5 且档内 listing ≥ 5 | 高需求低供给，目标档候选 |
| `gap` | 1.0–1.5 | 均衡 |
| `gap` | < 0.8 | 供给过剩，避开 |
| 档内平均评论数 | < 可比组中位数 × 0.8 | 壁垒可破 |
| 档内平均评论数 | > 可比组中位数 × 1.5 | 老链接把守，不打 |
| 档内新品数 | ≥ 3 | 有新人活下来，窗口存在 |
| 档内新品数 | 0 | 板结，无窗口 |
| 价格锚点区间 | 目标档中位价 × 0.95–1.05 | 允许区间，超出需理由 |
| 地板价 | 贡献利润率 = 8% 反解价 | 不可越过 |
| 测试段长 | 14 天/段 | 少于 14 天受周内波动污染 |
| 测试样本 | ≥ 60 单/段 | 不足则延长或改两段 |
| `\|e\|` | ≤ 1.0 | 可涨价（需求缺乏弹性） |
| `\|e\|` | 1.0–1.5 | 谨慎，单次涨幅 ≤ 5% |
| `\|e\|` | > 1.5 | 不可涨价，考虑降价或提客单（套装） |
| 单次调价幅度 | > 8% | 拆成两次，间隔 ≥ 14 天 |
| 调价禁区 | 上架前 30 天 / 大促前 14 天 | 不调价 |
| 评分 | < 4.0 | 先修评分再谈涨价 |

## 质检清单

- [ ] 5 档合计划量 = Top100，无漏项无重复。
- [ ] 主流带按同装量及有效单位数复算，样本最低价单列，缺可比样本已标待核。
- [ ] 分档模式已声明（固定档 / 分位点），切换理由写了。
- [ ] `gap` 的分母是供给占比（listing 数占比），不是金额占比。
- [ ] 目标档三条证据逐条给数，缺一条就不标「目标档」。
- [ ] 锚点已代入 05 层模型做红线校验，三条红线逐条过。
- [ ] 地板价给了反解过程，不是拍一个数。
- [ ] 测试方案写了段长、样本门槛、止损条件。
- [ ] 弹性用 A/C 两段实算，不是行业均值；无实测时标 `[C]`。
- [ ] 数据可信度声明：价格为抓取 `[B]`，销量为估计 `[C]`，弹性为实测 `[A]` 或未测 `[D]`。

## 反模式

1. **按均价定价**。错误：类目均价 $28，就定 $28。正确：按目标档中位价定，再看缺口档。
2. **只看销量占比找档位**。错误：$15–25 档销量最大就跟。正确：看 `gap`（销量占比/listing 占比），需求大但供给更多是坑。
3. **一次跳价 20%**。正确：单次 ≤8%，间隔 ≥14 天，拆两次。
4. **弹性用行业平均**。错误：「一般 −1.2」。正确：A/C 两段实测算 `e`，没测就标 `[D]` 且不给涨价结论。
5. **锚点不校验红线**。错误：$19.99 抢量但贡献利润 $1.8。正确：先反解地板价，锚点不得低于地板。
