# 主图 brief 模板与视觉差距 8 维评分卡（`visual-strategy` 专用）

## 1. 7 图槽位一览

| 槽位 | 名称 | 唯一目标 | 必含元素 | 禁止 |
|---|---|---|---|---|
| P1 | 白底主图 | 提升 CTR | 产品全貌、纯白底、占比 80%–88% | 文字、水印、Logo、道具、第二主体 |
| P2 | 结构/功能分解 | 证明卖点 | 剖面或爆炸图、1 个数字标注 | 多个卖点并列 |
| P3 | 场景图 | 提升转化（代入感） | 人手/使用动作、真实环境 | 纯摆拍物品、无人物 |
| P4 | 对比图 | 消除疑虑 | 本品 vs 普通款两栏、1 个对比维度 | 竞品品牌名、竞品实拍图 |
| P5 | 尺寸标注 | 降低退货 | in 与 cm 双单位、参照物（手/A4 纸） | 标注线遮挡主体 |
| P6 | 使用步骤 | 降低"不会用"差评 | 3 步内、每步 1 图 1 短句 | 超过 4 步 |
| P7 | 清单与售后 | 降低开箱纠纷 | 箱内清单平铺、质保与联系方式 | 促销语、价格 |

## 2. 主图 brief 填写模板（每张一节）

```
### P{n} {槽位名}
目标：{提升 CTR / 降低退货 / 消除某疑虑}
画面：{构图、产品占画面比例、光线、背景}
文案：{≤7 个英文词，无则为「无」}
证据：{数字或测试结论，例：承重 30 lb，200 次开合实测}
约束：{合规要求 + 最小字号 + 缩略可辨要求}
验收：{可量化，例：200×200 缩略下轮廓清晰，关键线条 ≥2 px}
```

## 3. 视觉差距 8 维评分卡（对手与我方同口径，各 0–5 分）

| 维度 | 0 分 | 3 分 | 5 分 | 权重 |
|---|---|---|---|---|
| D1 白底纯度 | 有背景/道具 | 白底但有阴影杂物 | 纯白、干净、无杂物 | 0.15 |
| D2 产品占比 | < 60% 或 > 95% | 65%–75% | 80%–88% | 0.15 |
| D3 文字合规度 | 文字面积 > 20% 或 P1 有字 | 10%–15% | ≤ 12% 且 P1 无字 | 0.15 |
| D4 场景图 | 无 | 1 张摆拍 | 1–2 张带人物使用 | 0.15 |
| D5 对比图 | 无 | 有但多维并列 | 单维、两栏、清晰 | 0.10 |
| D6 尺寸标注 | 无 | 单单位 | 双单位 + 参照物 | 0.10 |
| D7 A+ 结构 | 无 A+ | 有但 < 5 模块 | 5–7 模块且首屏为 M1/M2 | 0.10 |
| D8 视频 | 无 | 有但 > 60 秒 / 无钩子 | 30–45 秒 + 前 3 秒钩子 | 0.10 |

```
对手均分 = Σ(对手各维分 × 权重) 的均值（多 ASIN 取均值）
我方均分 = Σ(我方各维分 × 权重)
cmp_visual_gap = (对手均分 − 我方均分) / 5
```

## 4. 差距分级与投入建议

| `cmp_visual_gap` | 含义 | 投入 |
|---|---|---|
| ≤ 0.10 | 视觉不是瓶颈 | 只补 D6/D7 短板 |
| 0.10–0.20 | 轻短板 | 补 2 张图，预算 ¥3,000–5,000 |
| 0.20–0.30 | 明显短板 | 补 3–4 张图 + 重剪视频，预算 ¥8,000–12,000 |
| > 0.30 | 主要短板 | 全套重拍 + 视频重制，预算 ¥15,000–25,000；优先于文案投入 |

## 5. 视频首 3 秒三套钩子脚本

| 钩子类型 | 前 3 秒画面 | 前 3 秒台词/字幕 | 适用 |
|---|---|---|---|
| 痛点演示 | 旧产品断裂/漏水/装不上的特写 | "Broke in two weeks?" | 差评有明确失效模式时 |
| 结果前置 | 成品完成态 + 一键操作结果 | "One click. Done in 20 seconds." | 易用型产品 |
| 对比 | 普通款失败 → 本品成功，同机位同动作 | "Left: ordinary. Right: ours." | 有可量化结构优势时 |

硬规则：第 1 帧必须有产品实物；不做 Logo 开场；不做纯文字片头；首 3 秒不出现价格；音频前 3 秒有实际音效或人声，不放背景音乐淡入。

## 6. 点击率归因排查顺序

CTR 低时按此顺序排查，不要一上来就换主图：

1. 主图缩略（200×200 px）是否可辨 → 不可辨先修图。
2. 价格在搜索结果页是否高于同页中位价 15% 以上 → 是则先调价。
3. 评分是否 < 4.0 或评论数 < 15 → 是则先补评论。
4. Coupon 是否可见（绿色标签）→ 无则加 5%–8%。
5. 前四项都正常，才归因到主图创意本身（构图/场景/对比）。
