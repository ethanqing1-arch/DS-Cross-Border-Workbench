# 利润公式细则（`profit-model` 的计算底稿）

本文件把硬口径公式落成可代入的算式，并给出平衡点与敏感性的推导。**与 `SKILL_SPEC.md` 第 4.1 节冲突时，以 SPEC 为准。**

## 1. 公式（逐字照抄 SPEC 4.1）

```
tariff      = cogs_usd × tariff_rate      # 关税基数=申报货值，禁止按售价算
毛利        = price - cogs_usd - inbound - tariff
平台与履约  = price×referral_rate + fba_fee
推广        = price×ad_share
退货损耗    = price×return_rate×return_loss_ratio
贡献利润    = price - cogs_usd - inbound - tariff - 平台与履约 - 推广 - 退货损耗
贡献利润率  = 贡献利润 / price
盈亏平衡价  P* = (cogs_usd×(1+tariff_rate) + inbound + fba_fee) / (1 - referral_rate - ad_share - return_rate×return_loss_ratio)
cogs_usd    = cogs_cny / FX          # FX 默认 7.15，可配
```

派生（只做除法，不改公式）：`毛利率 = 毛利 / price`。

## 2. 关税基数（钉死）

- 基数 = `cogs_usd`，即申报货值。**不按售价、不按售价+头程。**
- 卖家有真实报关金额时，用"报关金额 ÷ 件数"替换 `cogs_usd` 参与计税，CSV 备注写"实报关"。
- 加征、豁免只改 `tariff_rate`，不改基数、不改公式。
- 同一批候选品必须同基数同汇率，否则贡献利润率不可比。

## 3. 三条盈亏平衡点（闭式解）

合并成两个中间量（`P` = `price_usd`）：

```
k = 1 - referral_rate - ad_share - return_rate × return_loss_ratio
F = cogs_usd × (1 + tariff_rate) + inbound_usd + fba_fee     # 与售价无关
贡献利润 = k × P - F
```

### 3.1 最低售价

| 约束 | 解法 | 含义 |
|---|---|---|
| 贡献利润 = 0 | `P ≥ F / k` | 不亏本下限 |
| 贡献利润率 ≥ 8% | `P ≥ F / (k - 0.08)`（要求 `k > 0.08`） | 红线 2 下限 |
| 贡献利润 ≥ 3 USD | `P ≥ (F + 3) / k` | 红线 3 下限 |

`最低售价 = max(三项)`，落到 `.99` 或 `.49` 价格带。

### 3.2 最高采购价

在当前售价下，目标 `T = max(0.08 × P, 3)`（红线 2、3 中更严者）。因 `tariff` 随 `cogs_usd` 联动，反解要除掉 `(1 + tariff_rate)`：

```
cogs_usd_max = [ k×P - inbound_usd - fba_fee - T ] / (1 + tariff_rate)
cogs_cny_max = cogs_usd_max × FX
```

`cogs_usd_max < 0` → 该售价结构下无论采购价多低都不达标，直接判"不可做"。

### 3.3 可承受最大 `ad_share`

```
ad_share_max = 1 - referral_rate - return_rate×return_loss_ratio
               - F/P - max(0.08, 3/P)
```

结果 < 0 表示结构上无法承载任何推广费；结果 > 0.45 按 0.45 封顶使用（新品期实际投放很少超过 45%）。

### 3.4 两条易错闭式（不要抄错）

| 写法 | 是否成立 | 原因 |
|---|---|---|
| `P* = F/k`，`F = cogs(1+tr) + inbound + fba` | 成立 | 与 `tariff = cogs×tr` 自洽 |
| `P* = (cogs + inbound + fba) / (1 - tr - ref - ad - r·l)` | **不成立** | 分母出现 `tr` 等价于关税按**售价**计征，与本包基数冲突；代入算例会高估 77% |

验算（算例参数，`cogs_usd 5.3147`、`inbound 2.10`、`fba 4.75`、`k 0.51`、`tr 0.25`）：

- 自洽式：`F = 5.3147×1.25 + 6.85 = 13.4934` → `P* = 13.4934 / 0.51 = 26.46`
- 混用式：`(5.3147+2.10+4.75) / (1-0.25-0.15-0.28-0.06) = 12.1647 / 0.26 = 46.79`
- 差 20.33 USD。混用会把"能不亏"的品判成"亏"，直接错杀。

## 4. 敏感性分析（四组 8 情景，每行一个情景）

| 情景 | 变量改动 | 其余参数 | 口径说明 |
|---|---|---|---|
| S1 | `cogs_cny` +15% | 不变 | 供应商涨价、汇率走弱；`tariff` 随 `cogs_usd` 联动 |
| S2 | `cogs_cny` -15% | 不变 | 换厂、加大起订量 |
| S3 | `price_usd` +10% | 不变 | 只算单位经济，需注明"涨价后销量可能下滑" |
| S4 | `price_usd` -10% | 不变 | 价格战情景 |
| S5 | `return_rate` +5pt（绝对百分点，封顶 0.60） | 不变 | 质量/尺码问题 |
| S6 | `return_rate` -5pt（封底 0.00） | 不变 | 改包装、上尺码表 |
| S7 | `ad_share` +10pt（封顶 0.60） | 不变 | 广告竞价上涨、竞争加剧 |
| S8 | `ad_share` -10pt（封底 0.00） | 不变 | 自然流量起量、转站内活动 |

每行输出：`情景 / 贡献利润(USD) / Δ贡献利润 / Δ% / 贡献利润率 / 是否破 8% / 是否破 3 USD`。破任一条标"抗压不足情景"，计入 `sensitivity_broken_count`。

## 5. 算例（可照抄核对引擎）

输入：`price_usd 34.99`、`cogs_cny 38`、`FX 7.15`、`inbound_usd 2.10`、`tariff_rate 0.25`、`referral_rate 0.15`、`fba_fee_usd 4.75`、`ad_share 0.28`、`return_rate 0.06`、`return_loss_ratio 1.0`。

| 行 | 算式 | 金额 USD | 占售价 |
|---|---|---|---|
| 售价 | — | 34.99 | 100.00% |
| 采购 | 38 / 7.15 | -5.3147 | 15.19% |
| 头程 | — | -2.1000 | 6.00% |
| 关税 | 5.3147 × 0.25 | -1.3287 | 3.80% |
| **毛利** | 34.99-5.3147-2.10-1.3287 | **26.2466** | **75.01%** |
| 平台佣金 | 34.99 × 0.15 | -5.2485 | 15.00% |
| FBA | — | -4.7500 | 13.58% |
| 推广 | 34.99 × 0.28 | -9.7972 | 28.00% |
| 退货损耗 | 34.99 × 0.06 × 1.0 | -2.0994 | 6.00% |
| **贡献利润** | 26.2466-9.9985-9.7972-2.0994 | **4.3515** | **12.44%** |

平衡点：`k = 0.51`、`F = 13.4934`。

| 项 | 结果 | 备注 |
|---|---|---|
| 最低售价 | 32.34 USD | 三项取 max：26.46 / 31.38 / 32.34，红线 3 最严 |
| 最高采购价 | 45.73 CNY | 现价 38，还有 +20.3% 空间 |
| 最大 `ad_share` | 31.9% | 现 28%，余量 3.9pt |

红线：R1 通过（75.01%）、R2 通过（12.44%）、R3 通过（4.3515 USD）、R4 由 `compliance-gate` 回填、R5 由 `supply-verify` 回填。

敏感性（基准 4.3515 USD / 12.44%）：

| 情景 | 贡献利润 | Δ | Δ% | 率 | 判定 |
|---|---|---|---|---|---|
| S1 采购 +15% | 3.3550 | -0.9965 | -22.9% | 9.59% | 通过，压线 |
| S2 采购 -15% | 5.3480 | +0.9965 | +22.9% | 15.28% | 通过 |
| S3 售价 +10% | 6.1360 | +1.7845 | +41.0% | 15.94% | 通过 |
| S4 售价 -10% | 2.5670 | -1.7845 | -41.0% | 8.15% | 通过，压线 |
| S5 退货 +5pt | 2.6020 | -1.7495 | -40.2% | 7.44% | 破 8% |
| S6 退货 -5pt | 6.1010 | +1.7495 | +40.2% | 17.43% | 通过 |
| S7 `ad_share` +10pt | 0.8525 | -3.4990 | -80.4% | 2.44% | 破 8% 且破 3 USD |
| S8 `ad_share` -10pt | 7.8505 | +3.4990 | +80.4% | 22.44% | 通过 |

`k` 与 `F` 的复算口径：`contrib = k×P - F`，其中 `k` 随 S5–S8 变、`F` 随 S1–S2 变、S3–S4 只变 `P`。

结论：单品过 5 条红线中的利润 3 条，但 2 个情景破线（S5、S7），按判定表"抗压一般"→ 结论最高"小批量观察"；动作是锁采购价 ≤ 45.7 CNY、把 `ad_share` 上限写进止损线、先测退货率。

## 6. 常见错误对照

| 错误 | 正确 |
|---|---|
| 先取整到 0.01 再连减 | 中间量留 4 位，展示层取 2 位 |
| `ad_share` 用"广告花费/订单数" | 必须是广告花费 / 销售额 |
| 退货损耗只算退款额 | 还要乘 `return_loss_ratio`（不可二次销售取 1.0） |
| 关税按售价算 | 按 `cogs_usd × tariff_rate` |
| FBA 取平均 $5 | 按尺寸分段查 `fba-fees.md` |
| 敏感性只给"±10% 影响不大" | 8 情景逐行出数，标破线项 |
