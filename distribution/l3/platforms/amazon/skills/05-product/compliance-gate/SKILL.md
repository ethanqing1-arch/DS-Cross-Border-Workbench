# 合规闸门（侵权四查 + 认证 + 类目限制 → 三态结论）

## 何时用

- 候选品外观"有点眼熟"，需要确认是不是别人专利或商标。
- 带电、液体、粉末、儿童用品，需要确认走什么认证、能不能上飞机。
- 竞品 listing 敢卖，但不确定自己有没有资质（医疗、化妆品、食品、杀虫）。
- 上架前最后一次闸门：不过就不能进"上架测试"。
- 要做欧洲站或多站点，需要看 EPR / VAT / 包装法。

不归这里：比价与交期 → `supply-verify`；算合规成本对利润的影响 → `profit-model`（把认证费摊销进 `inbound_usd` 或单列）。

## 输入契约

| 字段 | 来源 | 缺失时怎么办 |
|---|---|---|
| `product` | 候选品中文名 + 英文关键词 | **必需** |
| `category` | 品类 | **必需**（决定类目限制） |
| `material_spec` | 材质与工艺 | 缺失按竞品详情页填，标 `[C]` |
| `has_battery` | 是否含电池（内置/配套） | 缺失按"含"处理（保守），标 `[D]` |
| `is_children_product` | 是否 12 岁以下儿童用品 | 缺失按"是"处理（保守），标 `[D]` |
| `target_market` | US / EU / UK / JP | 缺失取 US，标 `[B]` |
| `brand_name` | 自有品牌名 | 缺失写"无品牌/白牌"，商标查改为查竞品品牌 |
| `ip_risk` | 本 skill 打分结果，0–10 | **必需**（本 skill 自己产出） |
| `cert_required` | 0/1 | **必需**（本 skill 自己产出） |
| `seller_qualification` | 卖家已有资质清单 | 缺失按"无"处理，标 `[D]` |

## 执行流程

1. **商标查（USPTO）**：打开 `tmsearch.uspto.gov`，用"产品核心词 + 竞品品牌名"各查一次，看 9/11/21/28 类是否有有效注册；同时 Amazon 前台搜该品牌名，看是否 Brand Registry 且卖同类。命中 → 记 `商标风险`。
2. **专利查（Google Patents + USPTO）**：搜"英文产品名 + design""英文产品名 + utility"，重点看 `D` 开头的外观设计专利与近 5 年实用专利；把最像的 1–3 个专利号与图、权利要求摘要抄进报告。命中外观 → 记 `外观专利风险`。
3. **版权查（图案/形象）**：对主图与印花做 Google 图片反搜；出现卡通形象、球队 logo、名画、影视角色 → 直接记 `版权风险`，不给整改空间。
4. **外观近似比对**：把自家样品/主图与竞品、与查到的 D 号专利图并排看 4 个特征（整体轮廓、分割比例、关键装饰、功能开口）。3 个以上特征重合 → `ip_risk` 起评 7。
5. **认证判定**：按 `references/compliance-matrix.md` 第 2 节对产品类型逐条匹配，列出"必需认证 / 谁出 / 周期 / 费用区间"。
6. **危险品与带电判定**：含锂电池看 `UN38.3` + 运输鉴定（空运 PI965/966/967）；含液体 > 100 mL、喷雾、强磁、易燃、粉末，逐个判定是否可空运/可 FBA。判"不可空运"→ 只能海运，`inbound_usd` 要重算。
7. **类目限制判定**：食品、化妆品、医疗器械、杀虫剂/农药、婴儿配方、激光产品，逐条查是否需要 FDA 注册/510(k)/EPA 注册；无资质 → 直接进"不可上"。
8. **市场合规（多站点才做）**：EU 查 CE + EPR（德国 VerpackG/LUCID、法国 EPR）+ VAT；US 查加州 Prop 65、复合木 CARB、各州包装 EPR（加州/俄勒冈/缅因/科罗拉多/明尼苏达）。
9. **打 `ip_risk`（0–10）**：按第 4 节评分表累加，封顶 10。`ip_risk ≥ 7` 触发红线 4。
10. **定 `cert_required`（0/1）**：任一必需认证卖家没有 → 1；全部已有或无需认证 → 0。
11. **出三态结论**：可上 / 需整改 / 不可上，规则见判定口径。
12. **写整改清单**：每条写"谁做什么、几天、验收物"，落盘三个文件。

取数口径：商标与专利查询必须记录查询日期与检索词；认证费用取 3 家检测机构报价的中位数；专利比对只比外观与权利要求，不做法律意见。

## 判定口径

三态结论：

| 结论 | 触发条件 | 后续动作 |
|---|---|---|
| 可上 | 四查无命中，`ip_risk ≤ 3`，`cert_required = 0` | 进入 `decision-control` 打分 |
| 需整改 | 有可消除项（改图案、换配色、补认证、换包装），且 `ip_risk ≤ 6` | 整改完成并复检后再进打分，不进"上架测试" |
| 不可上 | `ip_risk ≥ 7`；或命中版权（IP 形象）；或必需认证在目标市场无法取得；或类目无资质 | 换品，不投入任何开模与备货 |

`ip_risk` 评分表（0–10，累加封顶 10）：

| 风险项 | 分值 | 判定依据 |
|---|---|---|
| 商标命中（同类目有效注册） | +5 | USPTO 有有效注册且类目重叠 |
| 品牌词近似（读音/拼写差 1–2 字符） | +2 | 同类目已有近似标 |
| 外观专利命中（≥ 3 特征重合） | +6 | D 号专利图特征比对 |
| 外观专利可能命中（2 特征重合） | +3 | 需律师复核 |
| 实用专利可能命中（结构/机构相同） | +5 | 权利要求覆盖核心结构 |
| 版权命中（卡通/影视/名画/球队） | +8 | 图片反搜命中 |
| 竞品 listing 标注 patented / 独家 | +2 | 页面文案证据 |
| 无任何命中 | 0 | 四查留痕（日期 + 检索词） |

认证判定（`cert_required`）：

| 产品特征 | 必需认证 | 谁出 | 周期 |
|---|---|---|---|
| 任何电子/无线（含蓝牙、WiFi） | FCC（US）/ CE-RED（EU） | 第三方实验室 | 5–15 天 |
| 12 岁以下儿童用品 | CPC（US） | 第三方实验室 + 儿童产品证书 | 7–20 天 |
| 市电供电/加热/大功率 | UL 或 ETL | NRTL 实验室 | 3–8 周 |
| 含锂电池 | UN38.3 + MSDS + 运输鉴定 | 电池实验室 | 7–15 天 |
| 液体/粉末/化学品 | MSDS（SDS） | 第三方 | 3–7 天 |
| 食品接触（餐具、水杯、厨具） | FDA 食品接触声明 / LFGB（EU） | 第三方 | 5–10 天 |
| 化妆品/护肤 | FDA 设施注册 + 成分合规 | 合规代理 | 2–6 周 |
| 医疗器械（含美容仪部分品类） | FDA 510(k) 或列名 | 法规顾问 | 3–9 个月 |
| 杀虫/驱虫/抗菌宣称 | EPA 注册 | 法规代理 | 6–18 个月 |
| 复合木制品 | CARB P2 / TSCA Title VI | 供应商 + 检测 | 2–4 周 |

危险品与带电：

| 特征 | 判定 | 运输约束 |
|---|---|---|
| 内置锂电 ≤ 100 Wh | 可空运（PI967 Section II） | 需 UN38.3 + 鉴定报告 |
| 配套锂电（随货） | PI966 | 电池需独立包装 |
| 单独锂电 | PI965 | 多数货代拒收，只走海运 |
| 液体 > 100 mL | 限空运 | 需 MSDS，部分国家禁 |
| 气雾/喷雾 | 多数不可空运 | 只海运，FBA 需危险品审核 |
| 强磁（磁通 > 0.418 A/m @ 0.15 m） | 需磁检报告 | 空运需屏蔽包装 |
| 易燃/自热/腐蚀 | 危险品 | 绝大多数渠道拒收 |

## 输出契约

- 落盘：`out/<run_id>/合规判定.md`、`out/<run_id>/合规判定.csv`、`out/<run_id>/整改清单.md`
- CSV 列（对齐 `engine/score.py` 字段逐字一致）：`sku, category, product, ip_risk, cert_required, trademark_hit, patent_hit, copyright_hit, appearance_hit, cert_list, dangerous_goods, category_restricted, market_compliance, verdict`
- `verdict` 只允许三个值：`可上` / `需整改` / `不可上`。
- 本 skill 扩展列：`query_date, searched_terms, lawyer_review_needed, cert_cost_usd, cert_lead_days`
- 正文格式：先结论（一句：`verdict`、`ip_risk` 几分、缺哪些认证）→ 四查证据（专利号/商标号/截图日期）→ 认证与危险品表 → 整改清单。结论后标 `[A]`/`[B]`/`[C]`/`[D]`。

## 质检清单

- [ ] 商标、专利、版权、外观四查都做了，每条留了查询日期与检索词。
- [ ] 命中的专利抄了号与图，不是"感觉像"。
- [ ] 认证清单按目标市场给，没有把 CE 当 FCC 用。
- [ ] 危险品判定写了运输方式与是否需要鉴定报告。
- [ ] 类目限制逐条查过（食品/化妆品/医疗/杀虫/激光）。
- [ ] `ip_risk` 是累加算出来的，不是估的；≥ 7 已触发红线 4。
- [ ] `cert_required` 与 `seller_qualification` 对齐：卖家已有的不算缺。
- [ ] 数据可信度声明：本次四查为人工检索 `[B]`，未做律师意见；法律结论级判断需 `[A]` 或律师复核。

## 反模式

- 只搜关键词就判"不侵权"。→ 错：必须查图形商标、外观专利 D 号，并做 4 特征比对。
- "竞品在卖，说明没问题"。→ 错：竞品可能已授权、可能在被投诉、可能是权利人自己；平台在售不等于合规。
- 把 CE 当美国认证。→ 错：US 要 FCC/UL/CPC/Prop 65，EU 才用 CE。
- 含锂电只写"带电"。→ 错：要写 UN38.3、PI 代码、能否空运，否则头程报价全错。
- 结论写"建议咨询专业人士"。→ 错：必须落到三态之一 + 整改清单（谁做什么、几天、验收物）。
