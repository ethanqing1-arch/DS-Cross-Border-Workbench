# 电商客服处理

## 什么时候用

用户有一批买家消息要处理、要建话术库、要处理差评、或要每天巡检店铺。

## 回复结构：情 · 事 · 案 · 收

| 步 | 做什么 | 例 |
| --- | --- | --- |
| 情 | 先接情绪，别一上来丢条款。客户最激动时丢规则等于泼冷水 | 「这个情况确实让人着急，给您添麻烦了」 |
| 事 | 中性确认事实，不指责 | 「我帮您查一下订单，跟您确认几个细节」 |
| 案 | 给 1–2 个具体可执行选项（不是「我们再看一下」） | 「补发或退款，二选一，不用您寄回」 |
| 收 | 主动收尾，约定下一步和时间点，留后路 | 「我今天下班前给您进度，有问题随时找我」 |

**遇到情绪特别激动的客户，跳出模板用人话沟通**。模板是底线不是天花板。

四条规则：准确性（参数活动与后台一致，不说「大概/应该」）／共情力／简洁性（三行内，关键信息分段）／合规性（不越平台规则加码承诺）。

**不得把责任推给平台规定**——客户要的是解决方案，不是甩锅。

## 差评：写给还在观望的人看的

- 不是写给差评者，是写给后面所有潜在客户看的；决定转化率的是这些人在看你出事时怎么处理
- 50–80 字，语气诚恳，不反驳、不甩锅，重点展示「已处理」
- 先解决买家的实际问题，不要求或引导买家修改或删除评价。买家主动提出改评或删评时，不施压、不承诺任何利益。涉及平台规则，以卖家后台当期政策为准。
- 差评汇总后真正该改的是商品页描述、打包流程、供应商质量——改一处能少几十条

## 工单优先级

| 级别 | 场景 | 时限 |
| --- | --- | --- |
| 高 | 破损、投诉、差评、地址修改、物流丢件、仅退款 | 30 分钟 |
| 中 | 发货时效、批发询价、砍价 | 2 小时 |
| 低 | 库存、价格、尺寸、材质、发票、优惠券 | 4 小时 |

**仅退款判断**：金额 **< 50 元** → 直接同意（走流程沟通成本高于货值）；**≥ 50 元** → 要求开箱视频/照片再走平台介入。

## 转人工红线（脚本内置，不要绕过）

投诉 / 差评 / 律师 / 工商 / 消协 / 12315 / 举报 / 骗子 / 假货 / 平台介入 / 仅退款 / 起诉 / 曝光

命中任一词 → 一律转人工，不发自动回复。

## 素材与命令

所有相对路径（`data/…`、`scripts/…`、`out/…`）以**当前 Bot 的 work_dir（团队工作区根）**为基准，不是 shell 的 cwd；
Bot 没有独立 work_dir 时，用团队工作区根。

- 随包：`scripts/` 下 4 个脚本与 `data/faq.json` 由 L2 装进工作区（本 skill 用 `cs_router.py`）；`data/messages.csv` 需自行导出
- 话术库 `data/faq.json`（19 意图 + escalate 风险词 + fallback）
- 消息 `data/messages.csv`（时间/买家ID/订单金额/消息）
- 跑 `python3 scripts/cs_router.py`
- 产出 `out/客服处理.csv`、`out/店铺巡检清单.md`

## 执行流程

1. 导出消息成 `messages.csv`。
2. 跑脚本，看三块：转人工 / 未命中 / 高优先级。
3. **补话术库**：新问题写进 `faq.json` 的 `intents`，关键词 ≥3 个，要含买家口语说法。
4. 重跑，确认未命中数下降（这是自动回复越用越准的闭环）。
5. 按巡检单处理今日工单。

## 店铺巡检三样（每天定时跑）

1. **差评与追评**：新差评全部挑出，按严重程度分类
2. **商品状态**：有无违规下架、库存是否低于预警线、**有无商品还在投广告但已零库存**（最常见也最浪费钱）
3. **竞品动态**：改价、上新、活动（浏览器自动化定时抓）

## 健康指标

首次响应 ≤3 分钟 ｜ 纠纷介入率 ≤0.5% ｜ 差评率 ≤1% ｜ 高频话术背后的源头问题（哪条话术被频繁调用，说明那个场景问题高发，不是客服的问题）

## 汇报格式

```
消息 25 条 ｜ 转人工 5（20%）｜ 高优先级 5 ｜ 未命中 0
工单：咨询 10 / 价格 5 / 物流 4 / 投诉 3 / 售后 1 / 质量 1
今日必处理：
1. u_1004 投诉平台 → 风险，30分钟内人工接手
2. u_1007 磕坏 → 补发或退款二选一，不用寄回
3. u_1023 仅退款 39.90 < 50 → 直接同意
```

## 边界

- 不承诺平台规则外的事（「保证退款成功」「一定赔偿」）。
- 不私自改价、不泄露其他买家信息、不索要密码/验证码。
- 自动回复只用于低风险意图；风险词命中脚本已强制转人工。
- 不得要求或引导买家删评改评。
