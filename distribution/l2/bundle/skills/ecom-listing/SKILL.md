# 商品上架与文案

## 什么时候用

用户要把选好的品做成可提交的商品素材，或要批量改标题、改价、下架、查违禁词。

## 内容是有结构可循的（不要当作文写）

**标题 = 核心词 + 属性词 + 长尾词**，一商品出三版，每版标主打搜索词。

| 平台 | 侧重 |
| --- | --- |
| 淘宝 | 搜索关键词密度 |
| 拼多多 | 规格与性价比表达，促销感 |
| 抖音 | 内容感、话题、场景 |
| 京东 | 品质与参数背书 |
| 亚马逊 | 英文关键词逻辑，核心词前置，≤200 字符 |

**详情页四段**：引入痛点 → 卖点展开 → 参数背书 → 售后保障。同时出长版（详情页）与短版（主图/短视频口播）。

多语言不是翻译是**本地化**：要给目标市场表达习惯、平台规则、当地计量单位。

## 合规：五类违禁词 + 一个关键判断

| 类别 | 词例 |
| --- | --- |
| 绝对化极限用语 | 最好/最佳/最优/最低价/最新科技；第一/全网第一/唯一/销量第一；首个/独家/首发/填补国内空白 |
| 虚假夸大功效 | 特效、神效、根治、永不反弹、当天见效、三天美白 |
| 无依据宣传 | 纯天然、野生、原生态、古法酿造、零甲醛（单独不一定违规，绑保健治疗必违规） |
| 虚假消费诱导 | 虚构清仓、虚构活动期限、虚构库存 |
| 疾病医疗术语 | 癌症、糖尿病、高血压、处方、疗程、医生推荐 |

**关键**：带「最」「第一」不必然违法，看语境——是否跨品牌全行业对比、是否误导消费者、是否贬低同行。同品牌自比或可验证客观事实可能合法。所以**机器只能标可疑，最终人判断**。

**流程四步不能省**：生成 → 检测 → 人工复核 → 上线。尤其价格、库存、功效承诺。

## 素材与命令

所有相对路径（`data/…`、`scripts/…`、`out/…`）以**当前 Bot 的 work_dir（团队工作区根）**为基准，不是 shell 的 cwd；
Bot 没有独立 work_dir 时，用团队工作区根。

- 输入 `data/products.csv`（SKU/商品名/类目/规格/售价/进价/运费/库存/主图数/卖点1-3/目标人群）
- 跑 `python3 scripts/gen_listing.py`（`--sku HM-001`）
- 产出：`out/上架包/<SKU>_<名>.md`、`out/合规检测报告.md`、`out/平台导入表.csv`、`out/上下架台账.csv`

## 执行流程

1. **补全商品表**。卖点必须是具体差异（「磁吸拼接」），不能是形容词（「质量好」）。
2. 跑脚本。
3. **逐项核对**（脚本只保结构，不保合规）：
   - 标题 ≤60 字，短标题 ≤30 字要能独立说清是什么
   - 合规报告里的 ❌ 必须改，⚠️ 逐个看语境
   - 贡献利润 > 8 元且贡献率 > 40%，否则重定价或换供应链
   - 库存与仓库实数一致，<30 件标低库存
4. **多店铺差异化**（避免被判重复铺货降权）：同一卖点换表达方式，脚本已出 A/B 两版详情。
5. **提交**：有后台用 `ego_*` 浏览器自动化按导入表逐条填，每填一个回读确认；没权限就把导入表+资料包交给用户。
6. **回填台账**：状态改「已上架」，填上架时间、平台商品ID、负责人。

## 下架与调价

下架触发：上架 14 天 0 销量且曝光 >500 ／ 退款率 >20% 连续 7 天 ／ 断货 >7 天 ／ 有违规记录。
调价保护：单次降幅 ≤15%，改价后 24h 内不再动。

## 汇报格式

```
已生成 6 份上架包
合规：必改 3 处（HM-003 销量第一/永不/零甲醛）、需人工判断 3 处
待人工确认：库存低于 30 件 1 个
导入表 24 行（6 SKU × 4 平台）｜ 台账状态仍为待上架
```

## 边界

- 脚本标题是模板拼装，必须再过一遍通顺度与关键词密度。
- 不代替用户做价格战决策，改价前提示贡献利润影响。
- 真实店铺提交时每步确认后再提交，不批量盲提。
- 不承诺平台规则外的退换与赔偿。
