# 电商选品分析

## 什么时候用

用户要选品、评估某个品能不能做、或要看同类竞争格局。
只问"某商品多少钱"不归这里，直接 web 搜索。

### 与另一个选品 skill 的分工

`market-research` 和本文都是选品流程，按下面这条硬线分，不要两套混用：

| 特征 | 用哪个 |
|---|---|
| 只要一个当场结论、不落盘、不读工作区模板、不做竞品档案 | **本文 ecom-selection** |
| 工作区里有 `90-templates/selection-score.md`、要出评分卡并落盘到 `10-market/candidates/`、要走 Scout 五步流水线并汇报给 Chief | `market-research` |

判不出来时看一条：用户有没有要求「存档 / 写进工作区 / 给 Chief 汇报」——有就转 `market-research`。

## 硬前置：三层利润模型

**不要用毛利率判断一个品能不能做。** 分三层：

| 层级 | 公式 | 用途 |
| --- | --- | --- |
| 毛利 | 收入 − 采购成本 | 只做初步判断，**不能定价** |
| **订单贡献利润** | 成交收入 − 商品成本 − 平台扣费（佣金+支付）− 物流包装 − 分摊推广费 − 退货损耗 | **判断能不能做** |
| 期间净利润 | 贡献利润 − 人工/仓储/软件/场地 | 判断整月赚不赚 |

经典翻车：售价 99、成本 35，看着毛利 64，扣完平台 3 + 佣金 12 + 投流 16 + 物流 8 + 退货 6，贡献利润只剩 19。

两条红线：

- 毛利率 < 25–30% → **不进付费测款**（广告一开就穿）
- 贡献利润率 < 8% → **不做付费主推**（除非有复购/后端利润）

两个必须固定的口径：

1. 推广费分摊：按点击归因 或 按销售额占比，**选定后不许换**，否则两个月数据不可比
2. 退货损耗：退回还能二次销售 → 只算运费+折损；不能再卖 → 全额损耗

## 素材与命令

所有相对路径（`data/…`、`scripts/…`、`out/…`）以**当前 Bot 的 work_dir（团队工作区根）**为基准，不是 shell 的 cwd；
Bot 没有独立 work_dir 时，用团队工作区根。

- 输入 `data/candidates.csv`（列：品类/商品名/1688进价/预估售价/运费/推广费率/平均退货率/月搜索量/在售竞品数/头部评论数/供应稳定性分/差异化点）
- 跑 `python3 scripts/score_products.py`（`--top N` / `--category 宠物`）
- 读 `out/选品打分.csv`

## 打分口径（脚本已实现，不要临时改权重）

| 维度 | 权重 | 算法 |
| --- | --- | --- |
| 需求强度 | 25% | log(月搜索量) 归一化 |
| 竞争压力 | 25% | log(竞品数)×0.7 + log(头部评论)×0.3，反向 |
| 盈利 | 30% | log(贡献利润额)×0.6 + 贡献利润率×0.4 |
| 风险 | 20% | 退货率惩罚×0.5 + 供应稳定性×0.5 |

≥60 上架测试 ／ 48–59 小批量观察 ／ <48 放弃。触发红线的品无论分数多高都不进「上架测试」。

## 执行流程

1. **收集三维度**（抓榜单后只看这三个）：
   - 销量**与增速**（静态销量高 ≠ 你还有空间）
   - 竞争密度（同款多少家在卖，价格带集中在哪段，前 10 名是不是全大店）
   - **竞品差评集中点** ← 信息量最大，竞品的差评就是你的机会点
2. 补齐字段：搜索量（生意参谋/巨量算数）、竞品数（搜索页"共 N 件"）、头部评论数（第一页最高销量宝贝）、退货率（类目经验值）、推广费率（付费流量占比，家居 20–30%，低价品 30–45%）
3. 跑脚本 → 读 CSV → 汇报
4. **SKU 分层**，每类动作不同：
   - 利润款（贡献率 ≥18%）→ 加备货加投放，作主推
   - 引流款（8–18%）→ 带来流量但不指望赚钱，控投放
   - 清仓款/不做（<8% 或负）→ 该清就清，别占资金

## 汇报格式

```
结论：3 可做 / 2 观察 / 1 放弃

可做
1. 宠物慢食舔食垫 69.7 分
   贡献利润 15.13/件（46.0%），利润款
   理由：竞品 1500、头部评论 4100，冷启动窗口还在
   动作：首单 100 件，主图打「吸盘防滑」

红线
- HM-003：毛利率<25%不进付费测款
```

## 边界

- 搜索量/竞品数是公开口径估算，结论要标「基于公开指数估算」，不包装成确定销量。
- 不预测能卖多少件，只给相对排序和动作。
- 品牌侵权、需资质品类（食品/化妆品/医疗器械）直接标"需资质"，不往下推。
- 贡献利润是估算，不是净利润；净利润要扣人工仓储，没数据不算。
